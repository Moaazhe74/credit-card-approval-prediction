# Credit Card Approval Prediction — Classification Project

## Overview

This project builds a machine learning classification pipeline to predict credit card approval outcomes based on applicant data.

## Problem Statement

Financial institutions receive many credit card applications and need a consistent way to assess approval decisions. This project uses classification models to predict whether an application is likely to be approved.

## Project Workflow

- Cleaned and prepared applicant data
- Handled numerical and categorical features
- Applied encoding and scaling techniques
- Trained and compared classification models
- Evaluated performance using F1-score, precision, recall, and confusion matrix

## Models Used

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Balanced / ensemble-based classification models

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Technologies & Skills

Python, Pandas, NumPy, Scikit-learn, Classification, Data Preprocessing, Model Evaluation
